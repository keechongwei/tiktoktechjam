# Robust AIGC Image Detection — SigLIP Linear Probe vs Qwen VLM with SFT

Detects AI-generated images with robustness to common post-processing
(JPEG compression, blur, resize, noise, color jitter, center crop), built
for TikTok TechJam's "Robust Detection of AI-Generated Images Under
Real-World Transformations" challenge.

## Overview

A frozen `google/siglip-base-patch16-224` vision tower (~203M params)
feeds a small trainable head.
(`LayerNorm -> Linear -> GELU -> Dropout -> Linear`) that outputs a single
confidence logit: 0 = real, 1 = AI-generated/tampered. Trained on
[`saberzl/SID_Set`](https://huggingface.co/datasets/saberzl/SID_Set) mixed
with a smaller pool from ModelScope's
[`hy2628982280/WildFake`](https://modelscope.cn/datasets/hy2628982280/WildFake/summary)
(~15% of training examples, 6 real + 6 diffusion-model categories, pulled by
`pull_wildfake_balanced.py`), with one of the hackathon's exact robustness
transforms (JPEG/blur/resize/noise/color/crop, at the spec's listed
severities) applied to 70% of training images from both sources — so the
model is trained to be robust to the same post-processing it will be
evaluated against, and to generalize across generators beyond `SID_Set`
alone, not just to clean images from a single source.

- **Tools**: Google Colab / Jupyter
- **Model**: `google/siglip-base-patch16-224` (SigLIP vision encoder only)
- **Libraries**: `transformers`, `torch`, `torchvision`, `datasets`,
  `scikit-learn`, `pandas`, `tqdm`, `remotezip`
- **Datasets**: `saberzl/SID_Set` (primary, train/validation) +
  `hy2628982280/WildFake` (secondary mix-in, train/eval)

## Repo contents

- `SigLIP_CLIP.ipynb` — end-to-end notebook: data pipeline (SID_Set +
  WildFake mix), training loop, robustness evaluation (clean vs. every
  transform/severity, plus a by-source clean-AUROC breakdown), error
  analysis (top false positives/negatives).

## Reproducing results

1. Open `SigLIP_CLIP.ipynb` in Colab (GPU runtime recommended).
2. Run the pip-install and Drive-mount cells.
3. Run the config/model-definition cell, then the training cell — this
   pulls the WildFake train/eval mix, streams `SID_Set`, trains the head 
   for `EPOCHS` epochs on the mixed (SID_Set + WildFake) stream with 
   robustness augmentation applied to 70% of images, evaluates each epoch,
   and saves a checkpoint per epoch to `OUTPUT_DIR`.
4. Run the **Robustness Evaluation** cell — scores the fixed evaluation
   sample (150 real + 150 AIGC SID_Set images, plus the WildFake eval pool)
   clean and under every transform/severity in the spec, writes 
   `robustness_summary.csv`, and prints a by-source (SID_Set
   vs. WildFake) clean-AUROC breakdown saved to `by_source_summary.csv`.
5. Run the **Error Analysis** cell — saves the top-8 false positives and
   false negatives (thumbnails + scores + source) to
   `<OUTPUT_DIR>/error_analysis/`.

## Scoring your own images

```bash
pip install -r requirements.txt
python score_directory.py \
    --input_dir path/to/images \
    --output_json predictions.json \
    --checkpoint path/to/classifier_epoch4.pt
```

Outputs a JSON list of `{"image_path": ..., "pred": ...}`, where `pred` is
the model's confidence (0-1) that the image is AI-generated.

## Limitations & what we'd improve with more time

- **Backbone stays frozen** — only the head is trained. Partially unfine-tuning the
  last few SigLIP encoder blocks would likely improve accuracy at the cost
  of more compute/time.
- **WildFake mix is intentionally light** — ~40 images/category for
  training, ~20/category for eval (bandwidth/time-bounded remotezip range
  requests), across 6 real + 6 diffusion categories. It's enough to check
  cross-dataset generalization direction, not enough to meaningfully move
  the model's decision boundary; a larger, longer pull would strengthen
  both the training signal and the by-source eval comparison.
- **No uncertainty/OOD signal** — a training-free approach using predictive
  uncertainty under weight perturbation (see `predictive uncertainty.pdf`,
  arXiv:2412.05897) could serve as a complementary, explainable signal
  alongside the trained classifier; not implemented in this build.
